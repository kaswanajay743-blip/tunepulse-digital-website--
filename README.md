# TunePulse Digital — Website starter
A responsive static landing website inspired by modern independent music distribution sites, with original TunePulse branding.

## Before launch
1. Replace the contact email `hello@tunepulsedigital.com` in `index.html` with your confirmed business email if different.
2. Review service descriptions and do not publish platform/partner logos or claims unless you have permission/confirmed agreements.
3. Preview by opening `index.html` locally.

## Deploy to your existing Vercel project
1. Extract this ZIP.
2. Put `index.html`, `style.css`, and `script.js` in the root of the project connected to Vercel (or upload to a GitHub repository).
3. Commit/push to the connected GitHub repo; Vercel will deploy automatically.
4. Your domain is already configured in Vercel according to the screenshots. After deployment, visit https://tunepulsedigital.com and check SSL and mobile layout.

This is a static HTML/CSS/JS site; no build command is required. Vercel output directory can be left blank or set to the project root.
